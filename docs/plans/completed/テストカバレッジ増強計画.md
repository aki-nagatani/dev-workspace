## 6. 運用ルール

1. **実装とテストは同時進行**。テストなしコミットは禁止。
2. 標準実行は `pytest -n auto --cov`; 例外時は理由を本書に記載。
3. 新規/修正テストは共通フィクスチャ必須（`tests/fishtrack/conftest.py` / `tests/mypokedex/conftest.py`）。
4. `coverage_overall.json` 更新日は必ず本計画の数値も更新する。
5. `pragma: no cover` は到達困難性を明記した上で最小限に留める。

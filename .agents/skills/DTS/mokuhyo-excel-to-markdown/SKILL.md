### Excel の読み取り方法（ツール）

セル値の**確認・照合**（**BI1**・**BH4**・枝ごとの **C / U** 等）を行うときの**推奨手段**。**正本 Markdown への書き込み**は別節「**Markdown への書き込み（myrules・必須）**」に従う（読み取り専用の検証は本節のとおり）。

#### 正本スクリプト（読み取り専用・dev-workspace）

- **パス**: **`dev-workspace/scripts/read_hr_goal_sheet_xls.py`**
- **役割**: 本 SKILL の **BH4 / BS4 / BF6 / BI1 / BM1** および **枝1〜5**（基準行 `r = 18 + 4*(k-1)` と **C / U / AC / AF / AI / AS / BD / BS** 等）を読み、\
  **JSON またはテキストを標準出力に出すだけ**。**ファイルへの書き込みは行わない**（**`.md` を生成・上書きしない**）。
- **実行例**（カレントを `dev-workspace` とする）:

  ```text
  python scripts/read_hr_goal_sheet_xls.py "D:/.../72858（長谷晃英）目標-53上.xls"
  python scripts/read_hr_goal_sheet_xls.py --format text file1.xls file2.xls
  python scripts/read_hr_goal_sheet_xls.py --sheet 目標管理シート path.xlsx
  ```

- **依存**: **`.xls`** は **xlrd**、**`.xlsx` / `.xlsm`** は **openpyxl**（スクリプト先頭の docstring に同じ記載）。
- **運用**: エージェントはこの出力を参照して **`人事考課_管理シート.md` を `search_replace` / `write` 等で手作業反映する**。**スクリプトの出力をパイプして `.md` を機械生成すること**は **myrules**「ファイル修正と差分確認」に反するため**行わない**。

#### 拡張子とライブラリの対応

| 形式 | 拡張子 | 読み取りの目安 |
| --- | --- | --- |
| Excel 97–2003 バイナリ | **.xls** | **xlrd**（`xlrd.open_workbook(path)`）。**pandas** 利用時も `.xls` は **`engine='xlrd'`**（環境に **xlrd** が必要） |
| Office Open XML | **.xlsx** / **.xlsm** | **openpyxl**（`openpyxl.load_workbook(path, read_only=True)` 等）または **pandas**（**`engine='openpyxl'`**） |

- **.xls と .xlsx で API が異なる**ため、ファイルを開く前に拡張子で分岐する。
- 未導入の場合は **`pip install xlrd openpyxl pandas`** 等（**実行環境の Python／venv** に従う）。

#### A1 記法 → ツール上の行・列

- **Excel の行番号 `R`（1 始まり）** → 多くのライブラリの**行インデックス**は **`R - 1`（0 始まり）**。
- **列の A1 記法** → **列インデックス（0 始まり）**は `A=0, B=1, …, Z=25, AA=26, …`。**BH** 等は列番号に変換してから使用する。
- **xlrd** の例: `sheet.cell_value(rowx=R-1, colx=col_0based)`。
- **openpyxl** の例: `ws.cell(row=R, column=col_1based)`（**openpyxl は行・列が 1 始まり**のため、Excel の行番号と一致しやすい。**列だけ** A→1 始まりに変換する）。

- **Cursor の Read ツール**は `.xls` を**テキストとして開けず**、セル境界の解釈にも**不向き**。**セル単位の値**が必要なときは、**上記「正本スクリプト」**を使うか、**ターミナルで Python**（上記ライブラリ）を実行して読み取る。

#### 等級（BS4）と Markdown

- **Markdown** の **`###` 直下**（`- **メンバー**:` 行の **等級**）は**半角表記**とする（例: `G1`）。**BS4** が全角・句読点付きでも、**半角**に揃えて反映する。

#### 社員番号（BF6）と Markdown

- **BF6** から**社員番号**を取得し、**`###` 直下**のメンバー情報行（メンバー・等級と並べた 1 行）に記載する。**表記は常に 6 桁の半角数字**とし、**先頭ゼロを含める**（例: `072858`）。\
  Excel が**数値セル**の場合、表示上 **先頭ゼロが落ちる**ことがあるため、**数値として解釈したうえで `000000`〜`999999` 形式にゼロ埋め**して Markdown に書く。
- **Markdown の例**: `- **メンバー**: 長谷　晃英 ／ **等級**: G4 ／ **社員番号**: 072858`

#### 名前（BH4）と Markdown の照合

- **表記揺れに注意**: 姓名の**間のスペースの有無**、**半角スペースと全角スペース**の違いで、Excel（BH4）と Markdown の `###` メンバー見出しが**一致しない**ことがある。照合・検索の前に**正規化の基準**（スペースを入れる／入れない等）を揃える。
- **Markdown 側の原則**: メンバー名は **`###` 見出し**に**フルネーム**で記載する（略称のみ・姓のみに統一しない）。

#### 期内メンバー（`###`）の並び

**同一の `## 期` 内**における **`### 期 メンバー名` の並び**は、**社員番号**（Excel の **BF6**、Markdown 上は **6 桁**）の値による**昇順**を**正**とする（**上から先**）。\
Excel の取り込み・追記・ブロック移動のあと、該当期の **`###` がこの順と一致するよう** Markdown を整える。

- **比較**する整数は、**BF6** を数値化したものと**同一**（**SKILL**「**社員番号（BF6）と Markdown**」の 6 桁ゼロ埋めと**同じ**整数）。**072858** と **72858** は同じ並び位置になる。
- **照合の基準**: **`###` 見出しのメンバー名**は**フルネーム**とする（**姓のみ**の突き合わせはしない。**鈴木美玖**と**鈴木優介**は別人として扱う）。
- **BF6 が空**・**Markdown に社員番号が無い**・**同一社員番号が複数**・**並びが一意に決まらない**場合（新規・異動・表記ゆれを含む）は、**挿入位置・並び**を**ユーザーに確認**してから反映する。

### 枝番と行の対応（4行ステップ）

- 枝番の基準行 **A 列**: **A18, A22, A26, A30, A34** がそれぞれ **枝番 1〜5** の先頭行
- **一般化**: 枝番 `k`（1〜5）について **基準行** `r = 18 + 4 * (k - 1)`
- 以降の「*18」とある列は、**第1枝番**の例。**枝番 k** では列は同じ・**行番号は `r` に読み替える**

#### 枝番の並び（正本は Excel）

- **本文が空の枝番は Markdown に追加しない**（**`####` ブロック自体を置かない**）。Excel 上で当該枝の**通期目標（C 列・基準行）**および**取り込み対象の半期**に応じた主要セルが**いずれも実質空**（空白のみ）である枝は、**空の枝**とみなす。\
    同期時に **Markdown に当該枝の `####` が既にある**場合は**削除**する（見出しだけの枝は作らない・残さない）。
- **枝番の順序**は **Excel**（**A 列**の基準行に記載の **1〜5**）の**並び**を**正**とする。**空の枝**は **`####` を置かない**ため、**Markdown に現れる枝番**は **Excel の枝番のうち中身があるものだけ**。\
    （例: 枝 **5** が空なら **`#### … 5`** は**存在せず**、**1〜4** のみ並ぶ。**枝番の数字は Excel のラベルと同じ**で、**1 からの連番に振り直さない**。）
- **Markdown** の **`#### 期 メンバー 枝番`** の**並び**が、Excel の**中身のある枝**の**出現順**と**一致しない**ときは、**Markdown を書き換え**、**`####` ブロック順**を **Excel と同じ**にする（**`####` ブロック**単位の**並べ替え**を含む）。
- 各 **`####` ブロック**（`####` から次の `####` / `###` / `##` の直前まで）の**枝番**は、**対応する Excel の枝番 k**（**1〜5**）と**同じ数字**になるよう、\
    **`####` および配下のすべての `##### 項目 — 期 メンバー 枝番`** の**枝番部分**を**揃える**。**項目名**（通期目標など）は変えない。
- **並べ替え時**は、**`####` ブロック**（`####` から次の `####` / `###` / `##` の直前まで）を**単位**として移動し、その**直下の目標ジャンル行**も**同じブロックに含めて一緒に移動する**（枝番・ジャンル・本文の対応を維持する）。
- **目標ジャンル**の文言の**無断変更**は SKILL「**目標ジャンル**」に従う。**移動後**にジャンルと本文の意味が明らかにずれる場合は**ユーザーに確認**する。
- 並べ替え・本文の更新は **myrules** に従い、**スクリプトで当該 `.md` を一括生成しない**。

### Excel に無い項目

#### 目標ジャンル

- Excel には記載なし。**目標ジャンル**は Markdown 側のみ（各 `####` 直下の、`- **目標ジャンル**:` で始まる行）。
- **選び方（必須）**: **あらかじめリスト化された候補から選ぶ**。候補リストの**正本**は **`人事考課_管理シート_目標ジャンルリスト.md`**（上記「**目標ジャンル一覧（候補リストの正本）**」のパス）。**本ファイルにない表記**を管理シートに置く必要があるときは、**ユーザーに確認**し、**一覧の更新**（本ファイルへの追記等）と**管理シートへの反映**の順序を決めてから行う。
- **取り込み時**: 各 `####` について、通期目標等の内容と照らし、候補の中から**最も適切な1件**を選び、既存と同じ形式で目標ジャンル行に書く。
- **一覧に適切なものがない場合**（迷う／いずれも合わない／先例がなく候補が空に近い）は、**ユーザーに確認**してから記載する。**確認なしで、候補一覧にない独自ラベルを置かない**。
- **既存ブロックの上書き**: 当該枝の `####` が**既に存在する**ときは、**既存の目標ジャンル行を無断で上書きしない**。再同期で変える必要がある場合も**ユーザーに確認**する。

### 作業手順（エージェント）

#### 書き込み先がない場合

- **`#### 期 メンバー 枝番`** は、**その枝が上記「本文が空の枝番は Markdown に追加しない」の空でない枝**であるときに限り、**新規に追記する**。**空の枝**用の **`####` は追加しない**。
- **`## 対象の期`**、**`### 期 メンバー`**、**`#### 期 メンバー 枝番`**、または対象の **`##### 項目 — 期 メンバー 枝番`** のいずれかが **正本ノートに存在しない**ときは、**不足分を追記する**（反映を止めない）。
- 追記は **`人事考課_管理シート.md`** 先頭の「このノートの使い方」および**既存ノートの見出し順・階層**に合わせ、\
    **`##` → `###` → `####` → `#####`** の欠けているブロックを、**適切な位置**に**挿入**する。**`###` の位置**は上記「**期内メンバー（`###`）の並び**」に従う（**社員番号**で順序が決まらないときは**ユーザー確認**）。
- 枝番ブロックには **メンバー／等級**（`###` 直下）・**目標ジャンル**（`####` 直下）など、既存ノートと**同じ項目セット**を揃える。**目標ジャンル**は上記「**目標ジャンル**」に従い、**`人事考課_管理シート_目標ジャンルリスト.md`** の候補から選択（一覧にないときは**ユーザー確認**）。
- 追記で得た対象 **`#####`** の**直下本文**に、Excel の値を書く（空から始めてよい）。**上記「Markdown への書き込み（myrules）」に従い、スクリプトで一括生成しない**（`search_replace` / `write` 等で**段階的に**追記する）。

#### 書き込み先がある場合（上書き）

- 対象 **`##### 項目 — 期 メンバー 枝番`** の**見出し**は、**項目名**（通期目標など）—**期・メンバー名**は**変えない**。**枝番**は **Excel の枝番 k** と一致させる。
- **直下の本文**（当該 `#####` の次行から、**次の** `#####` / `####` / `###` / `##` の**直前**まで）を、Excel から読んだ値で**置き換える**（既存本文は**上書き**）。Excel の複数行はそのまま改行で反映してよい。
- **部分マージ**（既存と Excel をつなぎ合わせる等）は**しない**。Excel が**空・空白**のときは手順 **8** に従う。

1. **ファイル種別**を判定: ファイル名・内容から **上期**か**下期**か（両方ある場合はどちらを取り込むか確認）。**BM1** の **上期／下期**の表記と**一致するか**見る
2. **BI1** から西暦を読み、**期番号**を計算し、反映先 Markdown の**対象の期**（例: `## 54期`）と一致するか確認する（**BM1** の上期／下期とは**別軸**）
3. **BH4**・**BS4**・**BF6** から名前・等級・**社員番号（6 桁ゼロ埋め）**を取得し、**対象メンバー**の `###` / `####` 見出しと一致するか確認する（**名前**は上記「**名前（BH4）と Markdown の照合**」の表記揺れに留意。\
  **社員番号**は上記「**社員番号（BF6）と Markdown**」）
4. **目標ジャンル**: **`人事考課_管理シート_目標ジャンルリスト.md`** を開き、記載の候補一覧を正とする（上記「**目標ジャンル**」）。各 `####` には**一覧から最も適切なもの**を割り当てる。**一覧に適切なものがない**・**迷う**場合は**ユーザーに確認**してから記載する（必要なら**一覧ファイルを先に更新**）
5. 枝番 **1〜5** について、各 **基準行 r** の **A 列**が枝番と一致するか確認し、上表どおりセル値を読む。\
    **空の枝**は上記「**本文が空の枝番**」に従い **`####` を置かない／削除**する
6. **Markdown の `####` の並び**が **Excel の中身のある枝**の順と**一致しない**場合は、上記「**枝番の並び（正本は Excel）**」に従い、**`####` ブロックを並べ替え**、\
    **`####` / `#####` の枝番**を **Excel の k** に揃える（**項目名**は変えない）
7. Markdown では該当する **`##### 項目 — 期 メンバー 枝番`** の**直下本文**を更新（**項目名・期・メンバー**の見出しは維持、**枝番**は手順 6 に従い **Excel の k** と一致）。\
    **上記「Markdown への書き込み（myrules）」に従い、スクリプトで `.md` を書かない**
8. **Excel が空・空白のとき**:
    - **枝全体が空の枝**（上記「**本文が空の枝番**」）の場合: **`####` ブロックを置かない**。Markdown に**既に当該枝の `####` がある**ときは**ブロックごと削除**する。
    - **枝は中身があるが、特定の `#####` だけ空**の場合: 対象 **`#####` 直下の本文**は**空にする**（**`#####` 見出し行は維持**）。**Markdown に既存の本文がある**（空でない）場合は、**ユーザーに確認**する（本文を空にしてよいか、既存を残すか）。

# work-kadai-update

**`Work/`** 配下を触るときは先に **`work-folder-update` SKILL** を Read する（チャット情報の振り分けゲート）。

**`Work/課題.md`**（**現時点**の継続・未解決業務課題の**管理**正本）の **Read・追記・更新・削除**。手順は **`SKILL.md`**。\
**目標設定**（`mokuhyo-draft`）は本ノートを**参考**にするのみ（課題管理の目的は目標設定ではない）。

- **正本**: `D:/OneDrive/アプリ/remotely-save/Obsidian/Work/課題.md`
- **抽出元（Read のみ）**: `人事考課_管理シート.md` の**対象期より前**の達成状況コメント（**53期以前を含む**）。**解決済みは追記しない**
- **1 テーマ = 1 ブロック**・**常に最新の状況**（**最終更新** `YYYY-MM-DD`）。過去事実の四半期は **`54期4Q` 形式**。**打ち手に実施時期・頻度は書かない**（**ユーザー指示時のみ**）
- 同一テーマは原則統合。**次期案件L・次期L育成**は**要員ごとに1ブロック**（**SKILL**「同一テーマの統合」）。見出しは **`{カテゴリ}-01` + タイトル**（カテゴリ内連番・2桁）。空いた番号は再利用しない
- **カテゴリ**: 課題の**属する分野**（財務・CS・育成・稼働・労務・体制・人員 等）。一覧の `##` と **カテゴリ** 行を一致
- **編集**: **myrules**（**1 ブロック単位**の `StrReplace` / `Write`。**`replace_all` 禁止**）
- **`mokuhyo-draft`**: 目標下書きは別 SKILL（**課題.md は参照**）。**正本の更新は本 SKILL**のみ。下書きで課題が動いたときは **報告前に本 SKILL で正本同期**
- 完了後は **`obsidian-cursor-log`**。`課題.md` 編集後は **`markdownlint-fix`**

Always respond in Japanese when using this skill.

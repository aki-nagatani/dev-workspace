# mokuhyo-furikaeri（自身の振り返り・達成状況コメント本人）

**`人事考課_管理シート.md`** の**最新期**、**`###` が長谷　晃英**の各枝番について、**達成状況コメント(本人)** を下書きして反映する。

**更新するのは次のどちらか一方のコメントと、その半期の本人評価欄**（ユーザーまたは `評価の流れ.md` で決めた半期）:

- **`##### 上期達成状況コメント(本人)`**
  - 対応する **`##### 上期本人評価`**
- **`##### 下期達成状況コメント(本人)`**
  - 対応する **`##### 下期本人評価`**

**執筆者は長谷本人**。提出物は本人が書いた振り返りとして読めること。配下へ書く補助コメントではない。

**対象外**: 長谷以外のメンバー、**達成状況コメント(補助・１次評価者)**、補助評価、設定時コメント、本人の 12 項目（目標・達成基準・設定理由）。\
補助は **`mokuhyo-hojo-furikaeri-comment`**。目標の下書きは **`mokuhyo-draft`**（達成状況コメントは書かない）。

文体の禁止（メタ文、箇条書きの新設、総論調）は **`mokuhyo-draft`** の「本人の文体・AI 痕跡の禁止」に合わせる。\
**口調の正本**は、長谷の **N−1 期**の **同欄（達成状況コメント(本人)）**。目標文の口調だけで書かない。

myrules を厳守（**スクリプト一括置換禁止**・**報告前 CursorLog**・**Markdown は編集ツールでブロック単位**）。

**最初の作業（毎回必須）**: **本ファイル `SKILL.md` を全文 Read** してから着手する。

## 対象範囲

### 期と半期

1. **`## {数字}期`** の期番号最大を対象期とする。ユーザーが別期を明示したときだけその期にする。
2. **上期か下期か**は次の順で決める。
   - ユーザーが「上期」「下期」と明示 → それに従う
   - 未明示 → **`評価の流れ.md`** に当期の振り返り対象の半期があればそれに従う
   - それでも決まらない → **書かずに確認する**。暦の月から推測しない
3. 一度の実行で更新するのは**決めた半期の本人欄だけ**。もう一方の半期は触らない。

### メンバー

- **`### {期} 長谷　晃英`** 配下の各 **`####`** だけ。
- 長谷以外を「含めて」と指示されても、本 SKILL では書かない。
- 「この枝番だけ」と明示されたときはその枝番だけ。

### 触らない

補助コメント、設定時コメント、12 項目、目標ジャンル、メンバー行、**`<改善案>`**、**対象期より前**。対象期より前は **Read のみ**。\
ユーザーから上期・下期の状況連携を受けた場合は、目標・達成基準・行動施策を変更せず、該当半期の **達成状況コメント(本人)** に反映する。目標側の修正は明示依頼がある場合だけ行う。

## 確定事実と仮案の区別

確定稿の実績の数値・件数・実施の有無は、次だけを使う。

1. ユーザーが**チャットで渡した実績**
2. ユーザーが**パスを指定した** Work ノートに、当該期・当該半期の実績として書いてある事実
3. 対象期・当該枝番の **達成基準**（ターゲット・ミニマム）は**突合の基準**であり、実績そのものではない

| 状態 | 対応 |
| --- | --- |
| 実績があり、達成基準と突合できる | 本人コメントを書く |
| 実績が無い | 目標・達成基準・N−1期の記載を参考に仮案を作成してよい。本文冒頭に **`（要確認・仮）`** を付け、仮の実績・状況・自己評価を含める場合も同じマーカーで明示する。対応する本人評価欄にも仮の記号と **`（要確認・仮）`** を記載する |
| 一部だけある | 確認できた指標は事実として書き、未提示の指標は **`（要確認・仮）`** を付けた仮案として補ってよい。確定情報と仮案を同じ断定レベルで扱わない |

- **通期目標**に書いてある「昨年度〜」は、今期の実績にしない。
- **`課題.md`** の打ち手や課題文を、今期の実績として書かない。編集は **`work-kadai-update`**。
- 仮案または確認中の本文には、読者が確定稿と誤認しない位置に **`（要確認・仮）`** または同等の「要確認」を含む明示を付ける。実績確認後は、マーカーと仮の内容を確定内容へ差し替える。

## 書き方

### 構成（長谷の同欄に合わせる）

数値目標の枝は、N−1 期の本人コメントに近い形にする。

1. 先頭に指標名と実績（下期は通期の行も、実績が渡されているときだけ）
2. 達成基準との関係と、付けられるときだけ自己評価
3. 要因、または次にどうするかを**一人称**で短く（「〜したい」「〜継続する」「〜と考えている」）

### 金額の表記

売上高・利益額などの金額は千円単位で記載し、小数点以下を四捨五入する。金額に「約」は付けない。

定性の枝は、同じジャンルの N−1 期本人コメントの形に合わせる。売上型の見出しを無理に付けない。

### 自己評価の記号

N−1 期の本人コメントの付け方を目安にする。境界が曖昧なときは**記号を付けず確認**する。

| 実績と基準 | 記号 |
| --- | --- |
| ターゲットを上回り、過去の同欄が「大きく上回る」と書いている水準 | 「◎」 |
| ターゲット達成、またはターゲットに近い | 「〇」 |
| ミニマムは達成、ターゲットは未達 | 「△」 |
| ミニマム未達 | 「×」 |
| 判定材料が足りない | 記号を付けない |

### 到達状況の定型文

目標到達状況に応じた自己評価文は、次の定型文を使用する。

- `上期はターゲット目標を達成したため、自己評価は「〇」とした。`
- `上期はミニマム目標を達成したため、自己評価は「△」とした。`
- `下期はミニマム目標を達成できていないため、自己評価は「×」とした。`

仮案では暫定の自己評価記号を置いてよいが、本文冒頭と本人評価欄に **`（要確認・仮）`** を必須とする。確定稿では本人評価欄を記号だけにする。

### 口調

- **です／ます**。指示（「してください」）と **`（補助・長谷）`** は付けない。
- 毎枝番を「自己評価は「○」とした。引き続き取り組みたい。」の同型にしない。
- 「AI」「下書き」は本文に書かない。
- 分量は N−1 期の同欄に合わせる。結果の行に加え、本文はおおむね 2 段落。

### 既存本文

- **空欄**で実績が揃っている → コメントと対応する本人評価欄を反映してよい。実績未提示でも、上記のマーカー付き仮案と本人評価欄は反映してよい。
- **本文が既にある** → チャットで案を示し、ユーザーが差し替えを指示するまで上書きしない。
- 既存本文がマーカー付きの仮案・確認中表示の場合は、実績が提示されたときに確定内容へ差し替える。
- 本人評価欄が仮案の記号になっている場合は、コメントの仮案と同時に確定記号へ差し替える。

## 作業フロー

### 0. 前提

- 本 `SKILL.md` を全文 Read する。
- 対象期・半期を確定する。半期が決まらなければ止める。
- **`評価の流れ.md`** を Read する。**`課題.md`** は推奨（実績の正にはしない）。

### 1. Read

長谷の各枝番について、当該半期の達成基準、既存の本人コメント、対応する本人評価欄、**N−1 期の同欄**を Read する。実績が無い枝も、仮案または確認中表示を作成できるか判断する。

### 2. 文案

確定情報と仮案を区別していること、コメントの自己評価記号と本人評価欄が一致していること、一人称であること、署名が無いことを確認する。実績が欠けている枝は、仮案・要確認マーカーを付け、必要な確認項目をチャットに出す。

### 3. 反映

コメント欄と対応する本人評価欄を、それぞれ **`#####` 単位**で **`StrReplace`**（**`replace_all` 禁止）する。\
空欄または仮案だけ **`#####` 単位**で **`StrReplace`**（**`replace_all` 禁止**）。\
Work 配下なので反映前に **`work-folder-update` SKILL を全文 Read** する。

### 4. 検証

- 差分は対象期・長谷・決めた半期の本人コメント欄と対応する本人評価欄だけ。
- **`（補助・長谷）`** が付いていないこと。
- コメントの自己評価記号と本人評価欄が一致していること。仮案の場合は両方に **`（要確認・仮）`** があること。
- **`markdownlint-fix`** で管理シートの lint を解消する。

### 5. 報告

対象期、半期、書いた枝番、本人評価欄を更新した枝番、空欄のままにした枝番（足りない実績）を出す。

### 6. CSV と CursorLog

**`.md` を更新した同一セッション**で **`mokuhyo-kanri-sheet-csv`** に従い CSV を更新する。続けて **`obsidian-cursor-log`**。

## 禁止事項

- 長谷以外の達成状況コメントを書くこと
- **補助コメント**・設定時コメント・12 項目・もう一方の半期・対象期より前の変更
- 渡されていない実績・自己評価を、仮案・要確認の明示なしに確定稿として記載すること
- 本人コメントの自己評価記号と、対応する本人評価欄を不一致のまま残すこと
- **`（補助・長谷）`** や配下への指示口調
- 既存の本人コメントの、指示のない上書き
- **スクリプト**による一括置換
- **`課題.md`** の編集

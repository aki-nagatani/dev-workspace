# mokuhyo-furikaeri

**最新期**の **長谷　晃英**について、**上期または下期**の **`達成状況コメント(本人)`** と対応する本人評価欄を下書き・反映する SKILL。手順の正本は **`SKILL.md`**。

- **更新項目**: 決めた半期の **`##### {上期|下期}達成状況コメント(本人)`** と対応する **`##### {上期|下期}本人評価`**（**長谷の `###` だけ**）
- **半期**: ユーザー明示を優先。未明示なら **`評価の流れ.md`**。それでも決まらなければ書かずに確認する
- **除外**: 長谷以外、補助コメント、設定時コメント、12 項目、もう一方の半期
- **事実**: 確定稿はチャットまたは指定ノートの実績と、当該期の達成基準だけ。実績未提示時は、目標・過去文をもとに仮の実績や自己評価を生成してよいが、コメントと本人評価欄に「要確認」と分かる仮案マーカーを付ける
- **口調**: N−1 期の本人コメント。一人称。**`（補助・長谷）` は付けない**
- **既存本文**: 空欄は実績が揃えば反映する。実績未提示時は「要確認」と分かるマーカー付き仮案も可。確定済み本文は、差し替え指示まで上書きしない
- **配下の補助**は **`mokuhyo-hojo-furikaeri-comment`**。目標下書きは **`mokuhyo-draft`**
- **管理シートの正本**: Markdownのみ。CSVミラーは廃止し、作成・更新しない
- 完了後 **`obsidian-cursor-log`**。Markdown 編集後 **`markdownlint-fix`**

Always respond in Japanese when using this skill.

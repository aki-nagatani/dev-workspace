# mokuhyo-kanri-sheet-csv（管理シート CSV 同期）

**`人事考課_管理シート.md`**（Markdown 正本）と、**同フォルダ・同ベース名**の **`人事考課_管理シート.csv`**（Excel 作業用ミラー）を**常にセット**で維持する。

**`mokuhyo-excel-to-markdown`**・**`mokuhyo-draft`**・**`mokuhyo-proofread`**・**`mokuhyo-hojo-setteiji-comment`** のいずれかが **管理シート `.md` を変更した同一セッション**では、**CSV も必ず更新**する（**片方だけ更新して終了しない**）。

## 正本パス

| 用途 | パス |
| --- | --- |
| Markdown 正本 | `D:/OneDrive/アプリ/remotely-save/Obsidian/Work/社内業務/人事考課/人事考課_管理シート.md` |
| CSV ミラー（Excel 用） | `D:/OneDrive/アプリ/remotely-save/Obsidian/Work/社内業務/人事考課/人事考課_管理シート.csv` |

## CSV スキーマ

- **1 行 = 1 枝番**（`#### {期} {メンバー} {枝番}` ブロック）
- **列（23）**: `期`, `メンバー`, `等級`, `社員番号`, `枝番`, `目標ジャンル`, および次の **17 項目**（`#####` 見出しの項目名と同一）

  通期目標, 上期目標, 下期目標, 通期達成基準（ターゲット）, 通期達成基準（ミニマム）, 上期達成基準（ターゲット）, 上期達成基準（ミニマム）, 下期達成基準（ターゲット）, 下期達成基準（ミニマム）, チャレンジ度, ウェイト, 設定理由（本人）, 設定時コメント(補助・１次調整者), 上期達成状況コメント(本人), 上期達成状況コメント(補助・１次評価者), 下期達成状況コメント(本人), 下期達成状況コメント(補助・１次評価者)

- **文字コード**: **UTF-8 BOM**（`utf-8-sig`）。Excel（Windows）での文字化け防止。
- **改行を含むセル**: RFC 4180 準拠の CSV クォート（`"` で囲み、内部 `"` は `""`）。

## CSV に含めないもの

- **`## このノートの使い方`** など期・枝番に紐づかない節
- **`<改善案>` … `</改善案>`** ブロック（**`mokuhyo-proofread`** の校閲メタ。**Markdown のみ**）

## 更新方法（エージェント）

### 原則（必須）

1. **`.md` を `StrReplace` / `Write` で変更したら**、**報告前**に **`.csv` を同一セッションで更新**する。
2. **正本は `.md`**。CSV は **派生ミラー**（Excel での一覧・フィルタ・コピー用）。**CSV だけ更新して `.md` を放置しない**。

### 全量再生成（推奨・既定）

**`dev-workspace/scripts/export_hr_kanri_sheet_to_csv.py`** を実行し、**stdout（BOM 付き UTF-8）** を **`人事考課_管理シート.csv` に書き込む**。

```text
# カレント: dev-workspace
python scripts/export_hr_kanri_sheet_to_csv.py
```

- スクリプトは **`.md` を読むだけ**（**`.md` への書き込みはしない**）。**myrules**「スクリプトで `.md` を生成・上書き禁止」と整合。
- **CSV への書き込み**は、スクリプト出力の取り込み（ターミナル経由の **1 ファイル上書き**）で行う。**`.md` の手編集差分とは別物**のミラー再生成として許容する。
- **枝番の追加・削除・並べ替え**・**複数メンバー**・**複数項目**の変更時は**必ず全量再生成**。

### 部分更新（例外）

**1 枝番・1〜2 列**だけの変更で、行の追加削除がないときは、該当 CSV 行を **`StrReplace`** で更新してもよい。**迷ったら全量再生成**。

## 逆方向（CSV → Markdown）

- **本 SKILL の範囲外**（ユーザーが Excel / CSV を直接編集した内容を `.md` に戻す作業は**別依頼**）。
- Excel 確定値の正本同期は引き続き **`mokuhyo-excel-to-markdown`**（**Excel ファイル**が入力）。

## 検証（報告前）

- `csv` モジュール等で **行数 ≒ `.md` の `####` ブロック数**（空枝番なしの枝のみ）を確認する。
- 直近編集した **期・メンバー・枝番**の代表列が **`.md` と一致**するか目視またはスポットチェックする。

## 関連

| SKILL | CSV 同期の要否 |
| --- | --- |
| **`mokuhyo-excel-to-markdown`** | **必須**（`.md` 反映後） |
| **`mokuhyo-draft`** | **必須**（対象期 `.md` 反映後） |
| **`mokuhyo-proofread`** | **必須**（`<改善案>` のみの変更でも全量再生成でよい。内容差分なしでも可） |
| **`mokuhyo-hojo-setteiji-comment`** | **必須**（設定時コメント反映後） |

完了後は **`obsidian-cursor-log`**（`.md` または `.csv` を変更した場合）。

# mokuhyo-excel-to-markdown

**目標管理シート**の Excel を Markdown（人事考課_管理シート）へ反映する。**目標管理（mokuhyo）系**コマンドのひとつ。今後、同系列で `mokuhyo-` 先頭のコマンドを追加する想定。

myrules を厳守して作業してください。

## Excel の提供（必須・先に確認）

- 本コマンドは、**呼び出しと同時に**ユーザーが **目標管理シートの Excel** を提供する運用を正とする（チャットへの**添付**、またはワークスペース上の**パス明示**など、エージェントが内容を読める状態）。
- **Excel が提供されていない**（添付もなく、読み取り可能なパスも示されていない）場合は、**SKILL を実行しない**。**その旨をユーザーに指摘**し、ファイルを渡してから再実行してもらう。

## SKILL の適用（必須）

**最初の作業**として、\
`d:\OneDrive\git_work\dev-workspace\.cursor\skills\hr-goal-sheet-excel-to-markdown\SKILL.md` を Read で読み込み、\
**その手順・セル正本・制約に完全に従って**実行してください。`AGENTS.md` の要約と整合させる。\
**本文が空の枝番**は **`####` ブロックを追加しない**（既存があれば削除）。詳細は **SKILL**「枝番の並び（正本は Excel）」。\
**目標ジャンル**は **`人事考課_管理シート_目標ジャンルリスト.md`** の候補から選び、適切なものがないときはユーザー確認（**SKILL**「正本・前提」・「Excel に無い項目」→「**目標ジャンル**」）。

## 正本パス（SKILL と同一）

- **Markdown 正本（管理シート）**: `D:/OneDrive/アプリ/remotely-save/Obsidian/Work/社内業務/人事考課/人事考課_管理シート.md`
- **目標ジャンル候補の正本（一覧）**: `D:/OneDrive/アプリ/remotely-save/Obsidian/Work/社内業務/人事考課/人事考課_管理シート_目標ジャンルリスト.md`
- **入力**: 上記「Excel の提供」に従い、**同時に**渡された **目標管理シートの Excel**

## 禁止事項の再掲

- **myrules**「ファイル修正と差分確認」に従い、**すべての編集**において**スクリプトによる置換・書き換えは厳禁**。**例外**は設けない。
- 反映は **`search_replace` / `write` 等の複数回の編集**に寄せ、**枝番**・**`#####` 単位**など**追跡可能な単位**で行う。**一時スクリプト**（`temp/` の Python 等）で `.md` を機械一括変換しない。

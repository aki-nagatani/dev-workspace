# work-folder-update

**「仕事」＝株式会社DTSにおける本職**。FishTrack・MyPokedex・おたよりナビ等の**副職・趣味**（`DevProject/`・製品リポ含む）は**本 SKILL の対象外**。

**`Obsidian/Work/`** 配下を AI が **作成・更新・削除**するときは、**ファイル編集の前に** **`work-folder-update` SKILL**（`SKILL.md`）を **Read** して従う。

## 必須原則

- **チャットでユーザーから得た業務情報**は、**適宜相応のノートに記録として残す**（チャットだけで終わらせない）
- 例: **メンバー・体制** → `Work/体制・プロジェクト/`・`Work/メンバー/`、**課題** → `Work/課題.md`（**`work-kadai-update`**）、**人事考課** → `Work/社内業務/人事考課/`（**`mokuhyo-*`**）

## 発火

- `Work/` 配下の `.md` / `.csv` の作成・更新・削除
- `@Obsidian/Work` または Work 内パス指定の依頼
- **`work-kadai-update`**・**`mokuhyo-*`**・**`work-knowledge-deepen`** で Work を変更するとき（本 SKILL を先に Read）

## 併用

- 課題ブロックの書き方: **`work-kadai-update`**
- 管理シート・CSV: **`mokuhyo-kanri-sheet-csv`** 等
- Markdown 体裁: **`markdown-editing`** / **`markdownlint-fix`**
- 完了後: **`obsidian-cursor-log`**

Always respond in Japanese when using this skill.

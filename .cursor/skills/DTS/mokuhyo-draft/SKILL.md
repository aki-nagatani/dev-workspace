# mokuhyo-draft（人事考課・目標下書き）

**人事考課_管理シート**（Markdown 正本）に蓄積された**過去の目標・達成状況**を材料に、\
**今年度（対象の `## ◯◯期`）の上期目標設定**向けに、指定 **12 項目**の**下書き**を作成する。\
**上期の提出タイミング**で **下期目標**および**下期の達成基準**も**あわせて設定**する（後から下期ファイルだけで追記する運用ではない）。

**Excel への最終転記・確定値の同期**は **`mokuhyo-excel-to-markdown`** が正本。\
本 SKILL は **Obsidian 上の管理シート**への下書き反映（またはチャット提示のみ）を担う。

**前提（最重要）**: **目標管理の記載は依頼者本人が一から書くもの**である。エージェントの成果物は**本人の過去提出文に見えるたたき台**に限る。**AI が文章を作成したと第三者（上司・人事・同僚）に悟られる表現・体裁は禁止**（本 SKILL「本人の文体・AI 痕跡の禁止」）。

myrules を厳守して作業する。

## 前期以前の提出済み記載（絶対変更禁止）

**対象の期（今年度・下書き対象の `## ◯◯期`）より前**のすべての期（**前期・前々期…**を含む）は、**すでに提出済み**のため、管理シート上の**いかなる記載も修正してはならない**。

| 許可 | 禁止 |
| --- | --- |
| **対象期**の当該メンバー配下で、本 SKILL の **12 項目**のみ **Read／下書き／反映** | **対象期より前**の `##` 配下の **一切**の `###` / `####` / `#####` の **追加・削除・置換・空行調整** |
| 前期以前を **Read** して文案・数値の**参考**にする | 前期以前の **誤字修正・整形・目標ジャンル行の変更**（ユーザーが「過去期を直して」と明示しても、**本 SKILL では実行しない**） |

**編集時の必須**:

- **`search_replace` / `write`** の対象は、**見出し `## {対象期}` から次の `##` の直前まで**（当該メンバーのブロック内）に**限定**する。`old_string` には **`## {対象期}`** または **`##### … — {対象期} …`** を含め、**前期の見出しだけ**では置換しない。
- **`replace_all`** で **`人事考課_管理シート.md`** を触ることは**禁止**（前期以前への波及を防ぐ）。
- 反映後は、変更が**対象期の範囲内のみ**か**目視または diff で確認**する。前期以前に差分があれば**即座にユーザーに報告**し、**復旧を最優先**（復旧手順はユーザー指示に従う）。

**`mokuhyo-excel-to-markdown`** で前期の Excel を取り込む作業は**本 SKILL の対象外**。前期以前を直す必要がある場合は**別依頼・別 SKILL**とし、**本 SKILL の下書き作業と混在させない**。

**最初の作業**として、本ファイル（`dev-workspace/.cursor/skills/DTS/mokuhyo-draft/SKILL.md`）を **Read** し、全文の手順に従う。\
あわせて **参考資料**（上記正本パス）を **Read** する。

- **`評価の流れ.md`**: 評価・面談の前提確認。未整理の節は**推測で補完しない**。
- **`目標設定チェックポイント.md`**: 目標文案・達成基準の**品質チェック**（本 SKILL「参考資料：`目標設定チェックポイント.md` の使い方」）。
- **`課題.md`**: **現時点の課題管理**の正本（**Read 必須**・**更新は `work-kadai-update`**）。目標下書きでは**参考**として個々を読む。

要約は同ディレクトリの **`AGENTS.md`** と整合させる。

## 数値の扱い（仮値と確定値）

### 原則

| 段階 | 数値の扱い |
| --- | --- |
| **本 SKILL（ドラフト）** | 対象年度の**売上・利益率・件数・スコア・時間外平均**などは**仮値**で埋める。**最終確定値はユーザーが提示**するまで、前期実績を**そのまま今年のターゲットとして書かない**（実績の**参照・算出定義の例示**は可。下表） |
| **ユーザー提示後** | チャットまたはファイルで渡された**今年度の予算・KPI・組織目標数値**を**確定値**として反映する（**`（仮: …）` を外す**）。未提示の項目は**仮値のまま**残し、確定待ちを明示 |
| **Excel 確定同期** | **`mokuhyo-excel-to-markdown`**（ユーザーが Excel に転記した**確定値**が正） |

### 仮値の書き方（必須）

- 対象年度の**ターゲット／ミニマム**および目標文中の**今年度向け数値**は、ユーザーから**確定値が既に渡されている場合を除き**、次のいずれかとする。
  - **`（仮: 〇〇）`** — 具体数を入れるが**未確定**であることを明示（例: `（仮: 売上 1,200 百万円）`）
  - **`（仮: 要ユーザー提示）`** — 数値自体をまだ置かない（骨子だけ書くとき）
- **前期（N−1 期）の実績・当時のターゲット**を引用するときは **`（参考: N−1 期 …）`** または本文で **「前年度実績は …」** とし、**今年度の目標数値と混同しない**。
- **根拠のない新規数値の創作は禁止**（仮値でも**前年度・ユーザー文脈から妥当な桁感**に留める。完全な架空は不可）。

### 昨年度実績の記載（達成状況を正）

**通期目標**・**下期目標**等に **「昨年度通期の〜」「昨年度の〜」** として**前年度（N−1 期）の実績**を書くときは、**N−1 期の達成状況コメント(本人)**（**上期／下期**の振り返り本文）を**正**とする。

| 参照する（正） | 参照しない（誤りになりやすい） |
| --- | --- |
| **N−1 期**の **`##### 上期／下期達成状況コメント(本人)`** に記載の数値・事実（通期は**下期コメント**の通期行を優先。上期のみの指標は**上期コメント**） | **N−1 期**の **`##### 通期目標`** 内の **「昨年度通期の〜」** 行（**N−1 期の目標設定時**に書いたベースラインであり、**N−1 期の期末実績と一致しない**ことがある） |
| **N−1 期**の **達成基準（ターゲット／ミニマム）** と達成状況を**対比**してミニマム達成・未達の文脈を把握する | **N−1 期**の当時ターゲット数値を、今年度の**昨年度実績**としてそのまま転記 |

**手順（各枝番・実績行を書く前）**:

1. **N−1 期**の**同枝番**について **`##### 上期達成状況コメント(本人)`** と **`##### 下期達成状況コメント(本人)`** を Read する。
2. 今年度の **「昨年度〜」** 行は、上記コメントの**実績記載**に合わせる（**表記・単位**は **N−1 期の通期目標**の同種行の**書き方を踏襲**してよい）。
3. **上期のみ**・**下期のみ**の実績が分かれる指標（例: 売上・利益額）は、**N−1 期の下期目標**への**上期実績の追記**パターンがあれば、今年度の**下期目標**側にも**踏襲**してよい（54 期売上枝など）。

**達成状況コメントが空**、または当該指標の実績が書かれていない場合は、数値を**創作しない**。**`（要確認: 昨年度実績）`** とするか、ユーザーに確認する。

### 過去データから取ってよいもの／仮値にするもの

| 過去シートから | ドラフトでの扱い |
| --- | --- |
| **利益率・売上の算出式**、用語（期初見込み・確度 ABC 等） | **そのまま踏襲**可（数値は仮値化） |
| **N−1 期の実績値**（通期・上期） | **達成状況コメント(本人)** から転記（上記「昨年度実績の記載」）。**今年のターゲット数値そのものにはしない**（仮値で別記） |
| **N−1 期のターゲット／ミニマム** | **書き方のテンプレ**。**数値は `（仮: …）` に差し替え** |
| **ウェイト・チャレンジ度** | 前年度を**第一案**としつつ、変更時は変更点を説明（**合計 100** は維持） |

### ユーザーへの依頼

ドラフト提示時に、**仮値が含まれる枝番**を一覧し、**確定値の提示**（予算・組織 KPI・半期配分）を依頼する。**ユーザーが数値を渡したあと**、**別ターンまたは同一セッション**で **`（仮: …）` を確定値に置換**してよい（**確認なしの上書き**は、既存非空本文のルールに従う）。

## 過去データの参照と今年度の提案（必須）

**毎年度、新たな視点を持つことは非常に重要**である。エージェントは**前年度の写し替えだけ**で終えず、**新しい観点・行動・達成基準**を**積極的に提案**する（**チャット**で理由・根拠を示し、管理シート本文には AI メタ語を書かない）。

一方で、**過去を一切見ずにゼロから書くことは禁止**。対象期の **12 項目**を書く前に、対象メンバーの**過去期**（原則 **N−1 期**。同ジャンルが無いときは **N−2 期**まで遡る）の**同種記載**と **達成状況コメント(本人)** を **Read** する。

### 過去 Read と今年度提案の役割分担

| 観点 | 過去（N−1 期等） | 今年度（対象期） |
| --- | --- | --- |
| **必須** | 達成・未達の事実、昨年度実績数値、本人の振り返り・来期意向 | **N−1 の達成状況を踏まえた**改善・継続・新規の**行動**と**測定可能な達成基準** |
| **第一案** | 文体・口調、12 項目の書き分け、ジャンル・ウェイト | 前年度と**同趣旨でもよい**が、**文言・施策・基準は刷新してよい** |
| **提案（エージェント）** | — | **チャット**で枝番ごとに **「今年度の新視点」**（1〜3 点）を示す。採用可否はユーザー判断 |
| **管理シート** | — | 提案を反映した文案（**前年度文のコピペのみは不十分**） |

### 「同様の目標」の見つけ方（Read 用）

| 優先 | 照合の軸 |
| --- | --- |
| 1 | **同一メンバー**・**同一 `####` 枝番**（前年度と同じ枝番で継続するテーマ） |
| 2 | **同一または近い目標ジャンル**（例: 売上・利益・CS・時間外・人材育成） |
| 3 | **同一 `#####` 項目名**（通期目標・上期達成基準（ターゲット）等） |

### 今年度の新視点・提案の出し方（必須）

各枝番について、**N−1 期の達成状況コメント**と **12 項目**を Read したうえで、次を**チャットで必ず提示**する（管理シート反映の前後どちらでもよいが、**同一セッション内**）。

1. **継続** — 前年度から引き続き必要なこと（簡潔に）
2. **改善** — 未達・課題・振り返りから今年度に入れる**具体行動**（件数・頻度・証跡のイメージ）
3. **新規** — 前年度に無かった**観点・施策・達成基準**の候補（**`目標設定チェックポイント.md`**・**目標設定例（G4）**・組織目標・体制変化を材料に。**根拠のない空想は不可**）

**提案の材料**（優先順の目安）:

- **`課題.md`** に記載の**個々の課題**（**最優先で Read**。空でなければ**すべて**を対象に、チャットで **課題 ID → 枝番・打ち手** の対応を示す）
- **N−1 期**の **達成状況コメント(本人)**（未達要因・「来期は〜」・施策の実施／未実施）
- **`目標設定チェックポイント.md`**（行動目標・測定・証跡）
- **配下・体制・案件の変化**（管理シート・チャットで分かる範囲。**創作しない**）
- **6 本目以降の候補枝**（テーマの入れ替え・G4 例の未使用領域）— **提案段階**では提示してよい（本 SKILL「目標の本数」）

**管理シートへの反映**: ユーザーが**全面維持を明示**しない限り、**新視点・行動・達成基準**を**本文に織り込む**（前年度文の**最小限の写し**だけにしない）。**テーマの入れ替え**や**枝の追加**も**提案してよい**（確定はユーザー指示）。

### 表現・口調（本人に見える体裁）

**内容は毎年更新してよい**が、**書き方・口調**は過去の本人記載に揃える（第三者が読んでも**同一人物の続き**に見えること）。

| 揃える要素 | 具体例（過去文を Read して合わせる） |
| --- | --- |
| **文体** | 常体／ですます調、一文の長さ、句読点の付け方 |
| **口調** | 断定の強さ（「〜する」「〜していく」等）、謙譲・丁寧の度合い |
| **言い回し** | 接続（「また」「〜につき」「同上」）、社内用語（期初見込み・確度 ABC 等） |
| **構成** | 実績→目標の順など。**行動施策・達成基準**で箇条書きが必要なら、**過去の同種ブロック**（例: CS の行動施策列）の**体裁に合わせて追加・更新してよい** |
| **記号・表記** | 全角数字・単位（百万円・％）、括弧の使い方 |

**達成状況コメント(本人)** は**設定理由**・**通期目標**の**事実とトーン**の参考（コメント本文のコピペは不要）。

### 文案の作り方（各 `#####` ごと）

1. **過去**の同項目を Read し、**昨年度実績**（達成状況コメント準拠）と**課題**を整理する。
2. **今年度案**を書く — **継続・改善・新規**を反映。**前年度文をベースにしても、写しだけにしない**。
3. **数値**は本 SKILL「数値の扱い」に従い **`（仮: …）`**（ユーザー確定値提示済みなら確定値）。
4. **上期／下期**は前年度の**書き分けパターン**を参考にしつつ、**半期ごとの行動・基準**を今年度向けに更新してよい。
5. **チャット**に **「前年度からの変更点」** と **「今年度の新視点（提案）」** を枝番ごとに記載する。

### 数値との関係

- **対象年度の目標数値**は**仮値／ユーザー確定値**。**前期の数値をそのまま今年の確定ターゲットにしない**。
- **新しい達成基準**に伴う数値・件数は、**根拠ある仮値**または **`（仮: 要ユーザー提示）`** とする。

## 本人の文体・AI 痕跡の禁止

### 位置づけ

- **提出物**（管理シート・Excel 転記後）は**本人の自己記述**として読めること。**エージェント下書きである旨**を本文・注釈・メタ文に**書かない**。
- **チャット**では「下書き」「仮値」等の**作業用語**を使ってよい。**管理シートに反映する本文**には、**AI・生成・ドラフト**等の語を**入れない**（**`（仮: …）`** はユーザーと合意した**数値未確定の印**として可。確定後は外す）。

### 避ける表現（AI っぽさ・他年度と不整合）

過去の本人記載に**無い**次のような書き方は**原則使わない**（必要なら過去に近い言い換えにする）。

- 説教・総論調（「〜が重要です」「本質的に」「総合的に見て」）
- 過剰な丁寧・テンプレ（「〜に取り組んでまいります」「推進してまいります」の**一括追加**、毎段落の「以上」）
- **箇条書き・番号リストの新設**（過去が**段落のみ**なら段落のまま）
- 英語見出し・Markdown 装飾（`**太字**` の多用、見出し記号）— **管理シートは表なし本文**（先頭「このノートの使い方」）
- チェックポイント正本の**例文（§1〜3 の短い例・目標設定例（G4））をそのままコピペ**（**本人の過去文**を優先。G4 例は**構造・証跡の参考**に留める）
- 前年度と**明らかに違う語彙レベル**（漢語の急増、接続詞の統一しすぎ）

### 自然さの確認（提示・反映前）

各枝番の **12 項目**について、**N−1 期の同項目**と並べ、次を満たすか確認する。

1. **第三者が読んでも同一人物の続き**に見えるか（口調・文長・用語）
2. **今年度の新視点・行動・達成基準**が、**N−1 の振り返り**と**整合**しているか（**写し替えだけ**になっていないか）
3. **AI 作成を示すメタ情報**が本文に無いか

口調が不自然な場合は**過去文に寄せて書き直す**。内容の刷新は**維持**する（チェックポイントの改善は**表現を崩さない範囲**で行う）。

## 下書き作成の手順（エージェント）

### 1. 構造の把握

- 対象 **`## 期`** に **`### 期 メンバー`** があるか。無ければ **54 期（または直近期）の同一メンバー**を雛形に **`##` / `###` / `####` / 全 `#####` 見出し**を追加する（**`mokuhyo-excel-to-markdown`**「書き込み先がない場合」に準拠）。
- 追加する **`####` の数**は、**提案時**は候補本数に合わせる（**5 本候補なら 5**、**6 本以上**も可）。**ユーザー採用指示後**に **3〜5** へ整理する。**空の枝番は置かない**（`mokuhyo-excel-to-markdown`「本文が空の枝番」）。
- 枝番ごとに **`- **目標ジャンル**:`** を確認（**変更はユーザー確認後**）。**ジャンルが重複**しないよう配分する。

### 2. 枝番ごとに下書き（思考チェックリスト）

**`課題.md`** を Read 済みであること（本 SKILL「**`課題.md`（参照と同期）**」）。各枝番について、**当該枝に紐づく課題**（`課題.md` の**タイトル・本文・打ち手**。枝番対応は**チャット**で示す）と **N−1 期（同枝番・達成状況コメント）** を突合し、\
本 SKILL「**過去データの参照と今年度の提案**」に従い、**チャットで新視点を提案**してから **12 項目**の文案を作る。\
**`目標設定チェックポイント.md`** の **3 ポイント**と**セルフチェック 5 項目**も満たす。

- **通期目標**: **「昨年度〜」の実績行**は **N−1 期の達成状況コメント**を参照（本 SKILL「昨年度実績の記載」）。**今年度の目標・課題認識**は振り返りから**更新**。**目標数値**は **`（仮: …）`**（ユーザー確定値提示済みなら確定値）。
- **上期目標**・**下期目標**: 前年度の**書き分け**を参考に、**今年度の行動・マイルストーン**を明示（**「同上」**のみの丸写しは避け、同趣旨なら**一文で今年度の焦点**を足してよい）。
- **通期／上期／下期の達成基準（ターゲット／ミニマム）**: **測定可能**（件数・期限・証跡）。前年度より**厳しめ／新規行動**の基準を**提案してよい**。**数値は仮値**（`（仮: …）`）。
- **チャレンジ度**: 前年度を**第一案**（おおむね **1〜5** の整数。半角）。**新施策・未達課題**に応じて**上げ下げを提案**してよい。
- **ウェイト**: 前年度の**配分**を**第一案**。**テーマの重要度変化**があれば**変更案を提案**（**合計 100**）。
- **設定理由（本人）**: **組織目標・振り返り・今年度の環境変化**と**新視点の理由**を記載。**達成状況コメント**の「来期は〜」・未達要因を**織り込む**。

### 3. ユーザーへの提示（任意・併用可）

- 管理シートへ反映したうえで、必要に応じてチャットで **変更点要約・仮値一覧・要確認一覧**を示す（**全文の二重掲載は不要**）。
- 反映前にチャットだけで見せる場合も、**`目標設定チェックポイント.md`** の**セルフチェック表**で各枝番を照合し、未充足があれば修正または **`（要確認: …）`** を付す。
- 各枝番について **「今年度の新視点（提案）」** と **「前年度からの変更点」** を**必ず**示す（**継続・改善・新規**の区別が分かるように）。
- **`課題.md` に課題がある場合**は、**「課題一覧と目標への反映」**（課題 ID と枝番・打ち手の対応）を**必ず**示す。
- **仮値一覧**と **要確認一覧**をチャットまたはシート上の印のどちらかで追跡できるようにする。
- **固有名詞**や仮値以外の不確実事項は **`（要確認: …）`** と明示する（**シート本文にそのまま書いてよい**）。

### 4. 管理シートへの反映（随時・未確定可）

- 本 SKILL「**管理シートへの随時反映（未確定を含む）**」に従う。**ユーザー承認を待たず**、初回下書きから記載してよい（**対象期・当該メンバーに限定**）。
- **myrules**「ファイル修正と差分確認」に従い、**スクリプトで `.md` を一括生成・置換しない**。
- 編集範囲は **`## {対象期}` 内の当該メンバーのみ**。**前期以前の `##` には触れない**（絶対規則）。
- 対象 **`##### 項目 — {対象期} メンバー 枝番`** の**見出し行は変えない**。直下本文（次の `#####` / `####` / `###` / `##` の直前まで）を**置き換え**。
- 量が多いときは **`#####` 1 項目ずつ** `search_replace` で反映する。
- **`work-kadai-update` SKILL** に従い、当該セッションの**課題・打ち手・対応**を **`課題.md`** に反映する（**報告前**）。

### 5. 検証

- **前期以前に差分がないこと**（最優先）: 変更が **`## {対象期}`** のブロック内に**限定**されているか確認する。
- **文体・AI 痕跡**: 本 SKILL「**本人の文体・AI 痕跡の禁止**」の**自然さの確認**を実施したか。
- **markdownlint**: 管理シートを編集したら **`markdownlint-fix` SKILL** に従い、**同一ファイル内の指摘をまとめて解消**する（**前期以前の本文は lint 修正のために書き換えない**。対象期のみ）。
- **目視**: **12 項目**以外の `#####` 本文を**誤って消していないか**確認する（**対象期のみ**）。
- **`課題.md`**: チャットの **課題一覧・目標への反映** と **正本の `### {カテゴリ}-…`** が**矛盾していないか**（未反映の新規課題が残っていないか）。

## 禁止事項

- **前期以前**（対象期より前のすべての `## ◯◯期`）の**一切の修正**（**絶対**。上記「前期以前の提出済み記載」）
- **達成状況コメント**や**補助者コメント**の改変・捏造（**対象期でも**本 SKILL の更新対象外）
- **確認なし**での既存非空本文の上書き
- **目標ジャンルリストにないラベル**の無断使用
- **`目標設定チェックポイント.md` を Read せず**、主観だけの達成基準（「意識する」「貢献する」等**のみ**）で提示・反映すること
- **前期の数値を `（仮: …）` なしで今年度のターゲット／ミニマムとして転記**すること（ユーザーが**今年度の確定値として同数値を明示**した場合を除く）
- **N−1 期の `##### 通期目標` 内の「昨年度通期の〜」**を、今年度の**昨年度実績**として転記すること（**N−1 期の達成状況コメント**が正。本 SKILL「昨年度実績の記載」）
- **過去の同種目標・達成状況を Read せず**、当該 `#####` を**ゼロから新規作文**すること（本 SKILL「過去データの参照と今年度の提案」）
- **前年度の写し替えだけ**で今年度案を終えること（**新視点・行動・達成基準の提案**がチャットに無い）
- **今年度の新視点提案をチャットに示さず**、管理シートだけ更新すること
- **`課題.md` に未完了課題があるのに Read せず**、目標下書きを完了すること
- **目標提案・合意した課題**をチャットに示したまま、**報告前に `work-kadai-update` で `課題.md` を更新せず**終えること
- **過去の本人記載と明らかに異なる口調・文体**で管理シートに反映すること（本 SKILL「表現・口調」「本人の文体・AI 痕跡の禁止」）
- **管理シート本文**に **AI・生成・ChatGPT・ドラフト作成** 等、**本人以外が書いたと分かる語**を入れること
- **Python 等で管理シート全文を生成**して上書きすること（**myrules 違反**）

## CSV 同期（必須）

**`人事考課_管理シート.md`** を更新した**同一セッション**では、**`mokuhyo-kanri-sheet-csv` SKILL** に従い **`人事考課_管理シート.csv`** を**必ず**更新する（**片方だけで終了しない**）。

## Cursor ログ（必須）

**管理シート**・**CSV ミラー**・**`課題.md`**（または目標ジャンルリスト）を変更した作業完了後、報告前に **`obsidian-cursor-log` SKILL** で当日の CursorLog に記録する。

タグ例: `#人事考課` `#目標管理` `#mokuhyo` `#mokuhyo-draft` など。

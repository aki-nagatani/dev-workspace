# mokuhyo-draft

**上期の目標設定時**に、**人事考課_管理シート**の過去目標・達成コメントを参照して\
**今年度（対象期）の通期／上期まわりの下書き**を作る SKILL。手順の正本は **`SKILL.md`**。

- **絶対禁止**: **対象期より前**（前期以前・提出済み）の `##` 配下は **Read のみ・一切編集しない**（**SKILL**「前期以前の提出済み記載」）。
- **目標の本数**: **提案**は上限なし（**5 本候補は 4 本に事前絞り込みしない**・**6 本以上**も可）。**確定**はユーザー指示後に会社ルール **3〜5**（**SKILL**「目標の本数」）。採用要否・本数は**ユーザーが指示**。
- **更新する `#####` 項目**（**12 種**。上期設定時に **下期目標・下期達成基準**も含む）と**触らない項目**は **SKILL**「更新対象・更新しない項目」を正とする。
- **過去データ**: **必ず Read**（達成状況・12 項目）。**毎年の新視点・行動・達成基準をチャットで積極提案**（写し替えだけにしない）。**口調**は本人記載に合わせる（**SKILL**「過去データの参照と今年度の提案」「本人の文体・AI 痕跡の禁止」）。
- **本人記載として自然**: 目標管理は**本人が一から書く**前提。**AI 作成がバレる文体・メタ文は禁止**（管理シート本文に AI 等を書かない）。
- **数値**: **年度ごとに変わる**。**確定値はユーザー提示**。**ドラフトは `（仮: …）`**（**SKILL**「数値の扱い（仮値と確定値）」）。前期数値を今年の確定値として書かない。**昨年度実績**は **N−1 期の達成状況コメント**を正とする（**通期目標**内の「昨年度〜」行は不可）。
- **Excel 取り込み**は **`mokuhyo-excel-to-markdown`**。本 SKILL は**本人過去文に見えるたたき台**（内部作業用。提出物は本人の記述として読めること）。
- **管理シート反映**: **`（仮: …）`・`（要確認: …）` が残っていても対象期へ随時記載可**（**SKILL**「管理シートへの随時反映」）。確定後に対象期のみ差し替え。
- **Markdown への書き込み**は **myrules**（スクリプト一括置換禁止）。**`search_replace` / `write`** で **`#####` 単位**。
- 正本: **`Work/社内業務/人事考課/人事考課_管理シート.md`**。目標ジャンル候補: **`人事考課_管理シート_目標ジャンルリスト.md`**。\
  **参考資料**（作業冒頭で Read。数値・目標文案の正本ではない）:\
  **`Work/課題.md`**（**現時点の課題管理正本**。目標下書きでは**参照**。更新は **`work-kadai-update` SKILL**）、\
  **`評価の流れ.md`**（評価・面談の文脈）、\
  **`目標設定チェックポイント.md`**（行動目標・組織紐づけ・測定可能な達成基準・セルフチェック・**目標設定例（G4）**。**SKILL** 該当節）。
- 完了後は **`obsidian-cursor-log`**。Markdown 編集後は **markdownlint**。
- **校閲**（誤字脱字・チェックポイント・**`<改善案>`** 追記）は **`mokuhyo-proofread`** SKILL。
- **設定時コメント(補助・１次調整者)**（長谷以外・最新期）は **`mokuhyo-hojo-setteiji-comment`** SKILL。

Always respond in Japanese when using this skill.

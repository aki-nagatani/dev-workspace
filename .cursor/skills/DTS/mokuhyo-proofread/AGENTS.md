# mokuhyo-proofread

**人事考課_管理シート**の**最新期・全メンバー**を校閲する SKILL。手順の正本は **`SKILL.md`**。

- **対象**: ファイル内で**期番号が最大**の `## ◯◯期` と、その下の**すべて**の `###` メンバー（ユーザーが期・メンバーを限定指示した場合は例外）
- **観点**: **誤字脱字・表現**（**メンバー間の統一はしない**・**必要以上の改変禁止**）＋ **必須**で **曖昧な表現**・**基準の不明確さ**・**矛盾**（枝番単位で目標・達成基準を横断確認）＋ **`目標設定チェックポイント.md`** の方針整合（**組織目標の紐づけは内容で足りれば可・シートへの明記は不要**）
- **反映**: **既存本文は変更しない**。**指摘がある `#####` のみ**、本文直後に **`<改善案>`** と **`改善理由：`** を追記（**元の書式のみ**。コールアウト・索引見出しは付けない）
- **見つけ方**: 検索 **`<改善案>`**（一覧は校閲報告のチャット）
- **下書き作成**は **`mokuhyo-draft`**、**Excel 同期**は **`mokuhyo-excel-to-markdown`**（本 SKILL では行わない）
- **編集**: **myrules**（**1 ブロック単位**・**`replace_all` 禁止**・対象期より前は触らない）
- 完了後は **`obsidian-cursor-log`**。管理シート編集後は **`markdownlint-fix`**
- **設定時コメント(補助・１次調整者)** の生成は **`mokuhyo-hojo-setteiji-comment`** SKILL（本 SKILL は `<改善案>` 校閲のみ）

Always respond in Japanese when using this skill.

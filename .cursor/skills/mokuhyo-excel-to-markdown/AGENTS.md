# mokuhyo-excel-to-markdown

**ユーザーが Excel を渡したとき**に本 SKILL を参照する。人事の**目標管理シート（Excel）**を\
**Markdown（人事考課_管理シート形式）**へ同期するセル対応・手順は **`SKILL.md`** を正とする（**旧
`hr-goal-sheet-excel-to-markdown` は `SKILL.md` に統合済み**）。

**Markdown への書き込み**は **myrules**「ファイル修正と差分確認」に従い、**スクリプトによる置換は厳禁**。**複数回**の編集ツールで追記・置換する（詳細は **SKILL**「Markdown への書き込み」）。\
管理シートの正本は **`Work/社内業務/人事考課/人事考課_管理シート.md`**。\
**目標ジャンル**候補の正本は **`Work/社内業務/人事考課/人事考課_管理シート_目標ジャンルリスト.md`**（**SKILL**「正本・前提」）。

**Excel の読み取り**（**.xls** は **xlrd**、**.xlsx** は **openpyxl**、A1→行列入力の注意）は **SKILL**「**Excel の読み取り方法（ツール）**」を正とする。\
**読み取り専用の正本スクリプト**: **`dev-workspace/scripts/read_hr_goal_sheet_xls.py`**（**stdout のみ**・**`.md` へは書かない**）。

BH4 / C18 等の A1 記法、上期・下期の出し分け、枝番ごとの行 `r = 18 + 4*(k-1)` を含む。\
**枝番の並び**は **Excel を正**とし、Markdown と不一致なら **`####` ブロックの並べ替え**で揃える（**目標ジャンル行**はブロックに含め**一緒に移動**。詳細は **SKILL**「枝番の並び（正本は Excel）」）。\
**本文が空の枝番**は **`####` を追加しない**・既存があれば**削除**（詳細は **SKILL** 同節）。\
**メンバー見出しの `🔔`** は **SKILL**「**メンバー見出しの目印（🔔・残項目）**」— **`#####` 本文が空の項目が残るとき** `###` に付け、**外す条件**（**上期のみ反映**で下期が未取り込みのときは原則**外さない**等）は **SKILL** 同節を正とする。\
**同一期内の `###` メンバー並び**は **社員番号（BF6）昇順**（**SKILL**「期内メンバー（`###`）の並び」）。**一意に決まらない**ときは**ユーザー確認**。\
**社員番号（BF6）**は **6 桁ゼロ埋め**で **`###` 直下**に記載（**SKILL**「社員番号（BF6）と Markdown」）。\
**等級（BS4）**は **Markdown では半角表記**（**SKILL**「等級（BS4）と Markdown」）。\
**目標ジャンル**は Excel に無い。**`人事考課_管理シート_目標ジャンルリスト.md`** の候補から選択し、**一覧に適切なものがないときはユーザー確認**（**SKILL**「Excel に無い項目」→「**目標ジャンル**」）。
